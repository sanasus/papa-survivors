# Папа Выживает

Комедийный vampire-survivors-подобный экшен для браузера. Phaser 3 + TypeScript + Vite.
Всё PG: «сцены» — затемнение, дерево, сердечки и подпись «ЦЕНЗУРА».

## Запуск

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # production-сборка в dist/
```

## Управление

| Действие | Клавиши |
|---|---|
| Бег | WASD / стрелки |
| Выбрать «избранную» | ЛКМ по женщине или Пробел (ближайшая к курсору) |
| Отменить выбор | ПКМ |
| Пауза / звук | P или Esc / M |
| Выбор улучшения | 1 / 2 / 3 или клик |

Стрельба автоматическая.

## Правила

- **Пылкость** (шкала внизу) растёт сама, от числа женщин не зависит. Контакт сбрасывает её в 0.
- **Женщины** бегут к игроку. Выстрелы, розы, тапки и мегафон их не ранят, а *отшивают*: отбрасывают и оглушают.
  Избранная выстрелами не задевается и притягивается «лассо любви» без ограничений.
- **Контакт**: комедийная сцена (~1 с, игрок стоит, урон смягчён) → беременность → мать убегает.
- **Роды** в случайном месте через время, которое сокращается с каждыми родами матери (20 с × 0.82^(n−1), минимум 4.5 с).
  Сила ребёнка растёт с номером родов матери: n=1–2 обычные, n=3–4 элитки (рывок), n≥5 боссы (топот по площади).
  У детей-элиток и боссов подпись «Сын Люды №5».
- Мать отдыхает и возвращается в толпу, может забеременеть снова.
- **Переполнение шкалы**: беременеют все женщины сразу, шкала в 0, игра идёт дальше.
- Дети дают опыт (куда больше, чем мужья) и иногда подарок 🎁 (улучшение): 8% / 40% / 100% для обычных / элиток / боссов.
- **Победа**: продержаться 5:00 и убить финального босса — Тёщу. Она кидает тапки кольцами, делает рывки, зовёт «зятьков» и звереет на половине здоровья.

### Что добавлено сверх ТЗ

- Фоновая орда **ревнивых мужей** (обычные, бегуны, качки, метатели сковородок) и волны-«кольца» на 0:55, 1:55, 2:55, 3:55 — иначе в начале нечего стрелять.
- 5 видов оружия (поцелуй, розы, мамин тапок, борщ, мегафон) и 9 пассивок, среди них «Холодная голова» — замедляет шкалу.
- Имена матерей, счётчик их беременностей и титул «Мать года» на финальном экране.
- Три сложности, подсказки на экране, стрелка к боссу за краем экрана, рекорд в localStorage.
- Звуки синтезируются в WebAudio, внешних файлов нет.

## Баланс

Все числа лежат в [`src/config.ts`](src/config.ts) и [`src/game/upgrades.ts`](src/game/upgrades.ts).

Ключевая идея: сила игрока почти целиком идёт от детей, а дети — это риск.

- **Осторожно** (контакт, когда шкала почти полна): мало детей, мало опыта, зато спокойно.
- **Жадно** (спамить контакты): ~90 детей, ~30 уровней, но матери рожают всё более сильных — боссы приходят рано, смерти в середине забега.
- **Пассивно** (ждать переполнения): все женщины беременеют разом, ~100 детей пачками по 8–9.

По винрейту бота (нормальная сложность) все три стиля примерно равны (≈40%), различается профиль риска.

### Симуляция баланса

В игре есть бот и быстрая симуляция без рендера (≈1 с на забег). Откройте `http://127.0.0.1:5173/?go=1` и выполните в консоли:

```js
await __batch(10)                                   // 10 забегов бота на текущих настройках
await __batch(10, { rate: 1.2, hHp: 1.1 })          // с множителями (см. TUNE в config.ts)
await __batch(8, {}, { contactAt: 5, maxNear: 99 })  // «жадный» бот
await __batch(8, {}, { contactAt: 999 })             // «пассивный» бот
```

На момент сдачи бот выигрывает примерно: лёгкая ≈ 90%, нормальная ≈ 40%, жёсткая ≈ 20%.
Бот играет заметно проще человека (нет умного кайтинга), так что цифры ориентировочные.
